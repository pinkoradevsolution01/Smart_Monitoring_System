# Filipino Translation Quick Reference Guide

## How to Use Filipino Language in Smart Store Monitoring System

### Switching to Filipino Language

1. Open the application
2. Tap the **Settings** (gear icon) in the bottom right
3. Select **Language** option
4. Choose **Filipino** (FIL)
5. The entire interface will update to Filipino

### Common Financial Terms

#### Revenue Terms
- **Gross Revenue** = Kabuuang Kita (Total Income/Revenue)
- **Net Revenue** = Netong Kita (Net Income)
- **Growth Rate** = Rate ng Paglaki (Growth Percentage)

#### Expense Terms
- **Operating Costs** = Gastos sa Operasyon (Operating Expenses)
- **Transfer Fees** = Bayad sa Paglipat (Transfer Charges)
- **Total Expenses** = Kabuuang Gastos (Total Spending)

#### Profit Terms
- **Gross Profit** = Kabuuang Kita (Total Profit)
- **Net Profit** = Netong Kita (Final Profit after all expenses)
- **Profit Margin** = Margin ng Kita (Profit Percentage)

### Testing the Translations

#### Step 1: Enable Filipino Language
1. Tap Settings (gear icon)
2. Select Language → Filipino
3. See immediate UI update

#### Step 2: Test Sales Reports
1. Go to Owner Dashboard
2. Tap "View Sales Reports"
3. See "Ulat ng Benta" tab

#### Step 3: Test Financial Reports
1. Continue to Financial Reports tab
2. Verify tab shows "Mga Ulat sa Pananalapi"
3. Check date picker, refresh, and export buttons
4. Select a date to see financial metrics in Filipino

#### Step 4: Test Data Display
- Verify currency format: ₱ (Philippine Peso)
- Check metric labels in Filipino
- Confirm card titles translated
- Check insights text fully displayed

### Notes for Users

1. **Language Persistence:** Your language choice is saved automatically
2. **Application-Wide:** All screens support Filipino, not just Financial Reports
3. **Export Files:** CSV/PDF exports respect the language setting
4. **Date Format:** Dates display in YYYY-MM-DD format (universal standard)
5. **Currency:** Always shown as ₱ (Philippine Peso)

### Troubleshooting

**Issue:** Text appears in English after switching to Filipino
- **Solution:** Restart the application to refresh all screens

**Issue:** Some labels still show in English
- **Solution:** This is the key itself (fallback). File a bug report with the specific key name

**Issue:** Export shows English text
- **Solution:** Ensure Filipino is selected when exporting. File is generated in current language setting
