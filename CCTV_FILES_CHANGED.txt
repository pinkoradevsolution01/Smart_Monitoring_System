HOW TO USE
================================================================================

For End Users:
1. Open Owner Dashboard
2. Navigate to CCTV Monitoring
3. Click Settings (⚙️)
4. Enter camera RTSP URL
5. Click "Test Connection"
6. View live feed or access from sales log

For Developers:
1. Import: import 'package:smart_monitoring_system/services/cctv_service.dart';
2. Access: CCTVService.instance
3. Configure: cctv.configure(cameraUrl: '...')
4. Test: await cctv.testConnection()
5. Listen: cctv.addListener(() { ... })

For System Setup:
1. See CCTV_SETUP.md for camera configuration
2. See CCTV_QUICK_START.md for common setups
3. See CCTV_IMPLEMENTATION.md for technical details
